## Features

- A simple React Application developed using React-vite that display a list of products with images, prices, and descriptions
- User can add products to a shopping cart
- User can view the shopping cart with a list of selected products and total price
- User can remove items from the cart and update quantities
- The checkout button in the shopping cart redirects user to the main page 

## Built with

- Reactjs-vite 
- React router
- React icons
- HTML5 markup
- CSS3
